This folder contains my core **Amazon Route 53** notes focused on DNS management, domain routing, and cloud networking.

Each topic focuses on understanding how Route 53 and DNS routing work, not memorising configuration or deployment processes.

Examples are practical, infrastructure-focused, and tied to domain management, cloud networking, and DevOps workflows.

---

## Topics Covered

- [Amazon Route 53](./01-amazon-route53.md)  
  Understanding Amazon Route 53, DNS fundamentals, and managed domain services.

- [Hosted Zones](./02-hosted-zones.md)  
  Learning how hosted zones manage DNS records for public and private domains.

- [DNS Terminology](./03-dns-terminology.md)  
  Understanding common DNS concepts including records, resolvers, nameservers, and queries.

- [DNS Record Types](./04-dns-record-types.md)  
  Learning the purpose of A, AAAA, CNAME, MX, TXT, NS, and Alias records.

- [Routing Policies](./05-routing-policies.md)  
  Understanding Simple, Weighted, Latency, Failover, Geolocation, and Geoproximity routing.

- [Domains and Registrars](./06-domains-and-registrars.md)  
  Learning how domains are registered, managed, and integrated with Amazon Route 53.

---

## Learning Focus

- Understand Amazon Route 53 fundamentals
- Learn DNS records and hosted zones
- Understand routing policies and domain resolution
- Build a strong foundation for DNS management and cloud networking
