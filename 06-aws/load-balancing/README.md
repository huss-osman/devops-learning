This folder contains my Elastic Load Balancing (ELB) notes focused on traffic distribution, scalability, and highly available cloud applications.

Each topic focuses on understanding how Elastic Load Balancing services work, not memorising configuration or deployment processes.

Examples are practical, infrastructure-focused, and tied to scalable architectures, cloud networking, and DevOps workflows.

- [Scalability and High Availability](./01-scalability-and-high-availability.md)  
  Understanding scalability, redundancy, fault tolerance, and highly available cloud architectures.

- [Elastic Load Balancing](./02-elastic-load-balancing.md)  
  Learning how Elastic Load Balancing distributes traffic across multiple application resources.

- [Application Load Balancer](./03-application-load-balancer.md)  
  Understanding Layer 7 load balancing, listeners, target groups, and routing rules.

- [Network Load Balancer](./04-network-load-balancer.md)

- [SSL and TLS](./05-ssl-and-tls.md)  
  Understanding secure communication, encryption, and certificate management for web applications.

- [Auto Scaling Groups](./06-auto-scaling-groups.md)  
  Learning how Auto Scaling automatically adjusts application capacity based on demand.
