This folder contains my AWS Storage notes focused on persistent storage, machine images, and shared file systems.

Each topic focuses on understanding how AWS storage services work, not memorising configuration or deployment processes.

Examples are practical, infrastructure-focused, and tied to cloud storage, application persistence, and DevOps workflows.

## Topics Covered

- [Amazon EBS Volumes](./01-ebs-volumes.md)  
  Understanding Amazon Elastic Block Store (EBS), persistent block storage, and EC2 volume management.

- [AMI Overview](./02-ami-overview.md)  
  Learning how Amazon Machine Images (AMIs) are created, managed, and used to launch EC2 instances.

- [Amazon EFS](./03-amazon-efs.md)  
  Understanding Amazon Elastic File System (EFS), shared file storage, and scalable network file systems.
