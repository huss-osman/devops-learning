## Topics Covered

- [Containers on AWS](./01-containers-on-aws.md)  
  Understanding container technologies and how AWS supports containerised applications.

- [Amazon ECS](./02-amazon-ecs.md)  
  Learning the fundamentals of Amazon Elastic Container Service and cluster management.

- [ECS IAM Roles](./03-ecs-iam-roles.md)  
  Understanding task roles, execution roles, and IAM permissions for ECS workloads.

- [ECS Load Balancer Integration](./04-ecs-load-balancer-integration.md)  
  Configuring Application Load Balancers to distribute traffic across ECS services.

- [ECS Service Auto Scaling](./05-ecs-service-auto-scaling.md)  
  Automatically scaling ECS services based on demand and CloudWatch metrics.

- [Amazon ECR](./06-amazon-ecr.md)  
  Storing, managing, and deploying container images using Amazon Elastic Container Registry.

- [Amazon EKS](./07-amazon-eks.md)  
  Understanding Amazon Elastic Kubernetes Service and Kubernetes-based container orchestration.

- Understand AWS container services
