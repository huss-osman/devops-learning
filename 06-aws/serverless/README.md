This folder contains AWS Serverless notes focused on event-driven computing, managed services, and application development.

Each topic focuses on understanding how serverless services work, not memorising configuration or deployment processes.

Examples are practical, infrastructure-focused, and tied to event-driven architectures, cloud automation, and DevOps workflows.

---

## Topics Covered

- [Serverless Overview](./01-serverless-overview.md)  
  Understanding serverless computing, its architecture, and how managed services eliminate infrastructure management.

- [AWS Lambda](./02-aws-lambda.md)  
  Learning how AWS Lambda executes code in response to events without provisioning servers.

- [Lambda Benefits and Use Cases](./03-lambda-benefits-use-cases.md)  
  Understanding the advantages, common use cases, and real-world applications of AWS Lambda.

## Learning Focus

- Understand serverless computing fundamentals
- Learn AWS Lambda and event-driven architectures
- Understand managed compute services
- Build a strong foundation for serverless application development
