This folder contains my core **Amazon CloudFront** notes focused on content delivery, caching, and global application performance.

Each topic focuses on understanding how CloudFront distributions and edge locations work, not memorising configuration.

Examples are practical, architecture-focused, and tied to real-world web applications, cloud infrastructure, and DevOps workflows.
