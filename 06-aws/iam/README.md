![Service](https://img.shields.io/badge/Service-IAM-blue)

This folder contains my core **AWS Identity and Access Management (IAM)** notes focused on authentication, authorization, and cloud security.

Each topic focuses on understanding how IAM identities and permissions work, not memorising configuration or deployment processes.

Examples are practical, security-focused, and tied to identity management, access control, and DevOps workflows.

---

## Topics Covered

- [IAM Introduction](./01-iam-introduction.md)  
  Understanding AWS Identity and Access Management (IAM) and its role in securing AWS environments.

- [Users and Groups](./02-users-and-groups.md)  
  Learning how IAM users and groups simplify identity and permission management.

- [Permissions](./03-permissions.md)  
  Understanding how AWS permissions control access to services and resources.

- [IAM Policies](./04-iam-policies.md)  
  Learning how JSON policies define permissions and enforce least-privilege access.

- [Password Policy and MFA](./05-password-policy-and-mfa.md)  
  Configuring strong password policies and Multi-Factor Authentication for enhanced account security.

- [Access Keys, CLI and SDK](./06-access-keys-cli-sdk.md)  
  Understanding programmatic access using access keys, the AWS CLI, and AWS SDKs.

- [IAM Roles](./07-iam-roles.md)  
  Learning how IAM roles provide temporary credentials for AWS services and applications.

- [IAM Security Best Practices](./08-iam-security-best-practices.md)  
  Applying least privilege, credential management, and AWS security recommendations.

---

## Learning Focus

- Understand AWS IAM fundamentals
- Learn users, groups, roles, and policies
- Understand authentication and authorization
- Build a strong foundation for AWS security and identity management
