# Terraform Labs

![Debugging](https://img.shields.io/badge/Focus-Infrastructure%20Provisioning-purple)

This folder contains **hands-on Terraform labs** focused on practical infrastructure deployment and Infrastructure as Code.

The focus is on applying Terraform through cloud provisioning, infrastructure management, and deployment workflows.

Labs emphasise understanding Infrastructure as Code, Terraform state, resource management, and cloud deployment practices.

---

## Topics Covered

- [Deploying an EC2 Instance](./01-deploying-an-ec2-instance.md)  
  Provisioning AWS infrastructure using Terraform, including providers, resources, variables, outputs, and the Terraform workflow.

- [Importing Existing Infrastructure](./02-importing-existing-infrastructure.md)  
  Importing manually created AWS resources into Terraform state and understanding how Terraform begins managing existing infrastructure.

---

## Learning Focus

- Develop structured Infrastructure as Code workflows
- Learn how Terraform provisions and manages cloud resources
- Understand Terraform state and infrastructure lifecycle management
- Build confidence deploying and modifying AWS infrastructure safely
- Strengthen troubleshooting and operational skills using Terraform
