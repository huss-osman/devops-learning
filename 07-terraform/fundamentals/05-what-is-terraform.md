# What is Terraform?

## Overview

This section introduces **Terraform**, an **Infrastructure as Code (IaC)** tool used to provision, manage, and automate cloud infrastructure. It enables infrastructure to be defined in code, making deployments consistent, repeatable, and easier to manage across different environments.

It helps build an understanding of how Terraform works throughout the deployment lifecycle, making it essential for **cloud engineering**, **automation**, **Infrastructure as Code**, and modern DevOps workflows.

---

## What is Terraform?

**Terraform**  
An Infrastructure as Code tool that provisions, updates, and manages infrastructure using configuration files instead of manual configuration.

### Role in Modern Cloud Infrastructure

- Automates infrastructure deployment using code
- Provisions resources across multiple cloud providers
- Compares the desired infrastructure with the current infrastructure
- Creates, updates, and removes infrastructure safely
- Enables consistent and repeatable cloud deployments

Terraform follows a deployment workflow where infrastructure is first defined in code, then reviewed using a **plan**, before finally being provisioned using an **apply**. This helps engineers understand exactly what changes will occur before modifying cloud infrastructure.

---

## Key Takeaways

- **Terraform** is an Infrastructure as Code tool used to manage cloud infrastructure
- Terraform is cloud-agnostic and supports multiple cloud providers
- Infrastructure is defined using configuration files rather than manual configuration
- Terraform uses **plan** to preview changes before deployment
- Terraform uses **apply** to provision and update infrastructure
