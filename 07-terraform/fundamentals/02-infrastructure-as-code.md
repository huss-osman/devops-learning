# Infrastructure As Code

## Overview

This section introduces **Infrastructure as Code (IaC)**, an approach to managing and provisioning infrastructure through **code** rather than manual configuration. It enables cloud resources to be deployed consistently, repeatedly, and automatically across different environments.

It helps build an understanding of how modern infrastructure is managed, making Infrastructure as Code essential for **Terraform**, **cloud platforms**, **automation**, and modern DevOps workflows.

---

## Infrastructure as Code (IaC)

**Infrastructure as Code (IaC)**  
The practice of defining and managing infrastructure using configuration files instead of manually creating resources.

### Role in Modern Cloud Infrastructure

- Automates infrastructure deployment through code
- Creates consistent and repeatable environments
- Supports multiple cloud providers using the same workflow
- Reduces manual configuration and human error
- Enables infrastructure to be version controlled alongside application code

Infrastructure as Code allows engineers to provision cloud infrastructure in a reliable, scalable, and automated way across platforms such as AWS, Microsoft Azure, and Google Cloud.

---

## Commands

These tools help work with Infrastructure as Code:

- `terraform init` → Initialise a **Terraform working directory**
- `terraform plan` → Preview **infrastructure changes**
- `terraform apply` → Provision **cloud infrastructure**
- `terraform destroy` → Remove **Terraform-managed infrastructure**

---

## Key Takeaways

- **Infrastructure as Code (IaC)** manages infrastructure using code instead of manual configuration
- IaC improves consistency, automation, and repeatability
- Terraform is a cloud-agnostic tool that supports multiple providers
- Infrastructure can be version controlled and deployed through automated workflows
- Understanding IaC is fundamental for modern **cloud engineering** and **DevOps**
