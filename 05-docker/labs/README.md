# Docker Labs

![Containers](https://img.shields.io/badge/Containers-Docker-2496ED?logo=docker&logoColor=white)
![Debugging](https://img.shields.io/badge/Focus-Troubleshooting-purple?logo=docker&logoColor=white)
![Practice](https://img.shields.io/badge/Practice-Hands--on-orange)

This folder contains **hands-on Docker labs** focused on containerisation, Docker networking, and multi-container application workflows.


The focus is on troubleshooting containers, debugging service communication, and understanding how Docker behaves in real environments.

Labs emphasise investigation, logs, networking, and container debugging workflows.

---

## Topics Covered

- [DockerHub](./14-dockerhub.md)  
  Using DockerHub as a public container registry.

- [Pushing Images to Amazon ECR](./15-pushing-images-to-amazon-ecr.md)  
  Publishing Docker images to AWS Elastic Container Registry.

- [Using Images from ECR](./16-using-images-from-ecr.md)  
  Pulling and running images from a private AWS registry.

- [Debugging Networking Issues](./17-debugging-networking-issues.md)  
  Troubleshooting Docker networking problems between containers and services.

- [Multi-Stage Builds](./19-multistage-builds.md)  
  Creating smaller, cleaner Docker images using multi-stage builds.

---

## Learning Focus

- Develop structured Docker troubleshooting habits  
- Learn how to investigate container failures  
- Understand networking and service communication issues  
- Build confidence debugging multi-container environments  
- Strengthen operational and troubleshooting skills
