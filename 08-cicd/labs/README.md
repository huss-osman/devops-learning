# CI/CD Labs

This folder contains **hands-on CI/CD labs** focused on practical pipeline automation and GitHub Actions.

The focus is on applying CI/CD through automated workflows, testing, builds, security, and deployment processes.

Labs emphasise understanding GitHub Actions, workflow execution, pipeline automation, reusable actions, and software delivery practices.

---

## Topics Covered

- [Building a Simple CI Pipeline](./01-building-a-simple-ci-pipeline.md)  
  Creating a GitHub Actions workflow that automatically runs checks when code changes.

- [Conditions and Expressions](./02-conditions-and-expressions.md)  
  Controlling when jobs and workflow steps execute using conditions and expressions.

- [Matrix Builds and Parallel Testing](./03-matrix-builds-and-parallel-testing.md)  
  Running automated builds and tests across multiple configurations in parallel.

- [Using Secrets Securely](./04-using-secrets-securely.md)  
  Managing secrets and encrypted variables safely inside GitHub Actions workflows.

- [Creating a Custom Action](./05-creating-a-custom-action.md)  
  Building reusable custom GitHub Actions for automated workflows.

- [Manual Workflow Triggers](./06-manual-workflow-triggers.md)  
  Triggering and debugging GitHub Actions workflows manually.

---

## Learning Focus

- Develop structured CI/CD workflows using GitHub Actions
- Learn how pipelines automate testing, builds, and deployment
- Understand workflow events, jobs, steps, and actions
- Apply conditions, expressions, and parallel execution
- Manage secrets securely within automated workflows
- Build reusable and maintainable CI/CD automation
- Strengthen troubleshooting and pipeline debugging skills
